# Account ownership and recovery evidence

A transfer and claim settlement share an account-specific Web Lock and the common signing lock. Closing a signing tab releases the actual browser locks; another tab may then reconcile the original operation without expiring or deleting its signed checkpoint. An unresolved signed transfer blocks a new transfer or settlement. Continuation requires the original account, network, router deployment, checkpoint identity and revision, plus independently verified conversion evidence.

Recovery export uses an explicit public-field allowlist and reports source status as unknown. The bounded read-only comparison checks every distinct imported and stored signed hash against actual RPC/Horizon envelope and result evidence. It never chooses a winner by timestamp, overwrites the pending checkpoint, signs, or resubmits. A bounded sanitized public audit preserves both unresolved records. The comparison is keyboard accessible, cancellable and tied to the current stored checkpoint.
